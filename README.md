# TippAI – Updates

Dieses Repo enthält **nur** die fertigen Mac-Versionen von TippAI (notarisiertes ZIP unter *Releases*) und die signierte Update-Liste `appcast.xml`, aus der die App ihre Updates bezieht. Der Quellcode von TippAI ist nicht öffentlich.

- Updates kommen in der App über **TippAI → Nach Updates suchen …** (ab Version 1.6.0).
- Jedes Update ist doppelt signiert (EdDSA-Signatur + Apple Developer ID, notarisiert). Die App installiert nur, was beide Prüfungen besteht, und lehnt eine veränderte Update-Liste ab.
